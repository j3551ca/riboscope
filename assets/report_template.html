Treponema pallidum Results Summary

These results aim to monitor for novel mutations that may confer AMR in the ribosomal repeats, specifically the 16S and 23S rRNA genes of Treponema pallidum subsp. pallidum, the etiological agent of syphilis. Results are generated from calling mutations in reference-guided assemblies of short paired-end reads sequenced from amplicon-based libraries. QC filtration has been applied to results.

Sequencing Success of Amplicons for Each Sample

The success of failure of an amplicon (1 per gene & copy) was determined by whether the median count of short sequences located in the unique region of each amplicon were above or below a threshold value of {{ min_med_amp_count }}. These short sequences were detcted in the raw reads of samples as a proxy for presence or absence of each associated amplicon (see heatmap below). Samples that did not have at least 1 amplicon successfully sequenced resulted in failing QC.

SNVs Detected in rRNA of Treponema Pallidum

SNVs in each sample are listed on the x-axis, allele frequency on the y-axis, size depicts the number of samples that carry this same mutation, and color represents which of the ribosomal repeats (copies) the mutation is found in for a given sample. Hovering over each point displays this information in more detail. It is possible to zoom into the plot for further exploration. Samples without any successfully sequenced amplicons or pools (genes) that had neither repeat (copy) passing QC were removed from visualization. Mutations are displayed relative to position in each genomic feature. The same mutation may appear in multiple features when there are overlapping features. The original position along the reference sequence is found under "snv" when hovering over a mutation, while "feature_snv" shows the position of the mutation relative to the start of a specific feature from a given organism. The genomic features as well as the position are controlled by the user via GFF3 file. For example, a mutation may be reported relative to the start of a Treponema pallidum 23S rRNA gene or relative to an Escherichia coli 23S rRNA gene by simply aligning this gene to the reference and specifying the start and end positions in the GFF3 file. Subplots correspond to genomic features displayed along reference sequence below. Genomic features in purple are provided by user and those in pink are computed and labeled as "intergenic_n".

Taxonomic Classification of Reads in Each Sample

The taxonomic classification of reads by Kraken2 in each sample before and after dehosting. Dehosting is performed by discarding reads that did not map to the reference sequence of the target pathogen. Reads are categorized as pathogen, host, unclassified, and other for remaining reads. The figure shows what percentage of each sample the number of reads represents.

Relative Query Sequence Counts

Several pairs of short sequences (forward & reverse) unique to each amplicon were queried in the raw sequencing reads of each sample as a proxy for the presence or absence of each associated amplicon. During QC, the median of counts per amplicon was used to determine success.
